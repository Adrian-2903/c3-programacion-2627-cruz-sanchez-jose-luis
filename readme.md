# C3.Programación

Este repositorio contiene los **proyectos y recursos asociados a las guías y unidades de trabajo** que forman parte de los contenidos del curso.

## Estructura del repositorio

El contenido se organiza en dos niveles principales:

1. **Lenguaje de programación**
   - En el primer nivel hay una carpeta para cada lenguaje utilizado durante el curso.
   - De momento, la carpeta disponible es:

     ```text
     cs/
     ```

     correspondiente a **C#**.

2. **Guías y unidades de trabajo**
   - Dentro de cada carpeta de lenguaje habrá una subcarpeta para cada **guía** o **unidad de trabajo**.
   - Cada una contendrá los proyectos y recursos relacionados con sus contenidos.

Ejemplo de estructura:

```text
cs/
├── guia01/
├── guia02/
├── guia03/
├── ut01/
└── ...
```

## Versiones de los proyectos

Dentro de una guía o unidad de trabajo pueden aparecer **distintas versiones de un mismo proyecto**, correspondientes a los cambios que se van realizando a lo largo de los apartados.

Para identificarlas, se añadirá al nombre del proyecto el número del apartado en el que se produce la modificación.

Por ejemplo:

```text
HolaCS
HolaCS_10_4
```

`HolaCS_10_4` representa el proyecto **HolaCS** con las modificaciones realizadas en el apartado **10.4** de la guía correspondiente.

De esta forma, es posible consultar el estado del proyecto en distintos momentos del desarrollo de los contenidos sin perder las versiones anteriores.
